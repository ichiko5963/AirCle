# Launch vault filing (AirCle / 7_ローンチ)

## When this applies

- Paths under `04_Project/AirCle/7_ローンチ/` (無料セミナー・有料スクール・スクール設計・決済など).
- User says MTG / 打ち合わせ / スライド / 次のアクション / 実績 / 告知 などとローンチを一緒に言っているとき.

## Session folder map（各「第N回_◯◯」の直下）

| 番号 | フォルダ | 置くもの |
| --- | --- | --- |
| 00 | `00_セミナー概要` | コンセプト、タイトル案、台本・構成のたたき |
| 01 | `01_告知関連` | X / LINE / オプチャ / メルマガ / Peatix などチャネル別 |
| 02 | `02_スライド` | スライド用原稿・構成案・スピーカーノート相当（旧 `02_運営関連` は廃止） |
| 03 | `03_ミーティング` | **1会議1ファイル**。決定・宿題・次回までの論点のみ |
| 04 | `04_次回以降のアクション` | MTG外のタスク・フォロー・分析・**申込・参加などの数字**（期限・担当があれば明記） |
| 05 | `05_講座内容` | （ある場合のみ）当日の講義コンテンツ本体 |

## After a meeting（必須フロー）

1. `03_ミーティング` に `YYYY-MM-DD_テーマ.md`（または同じ規則のファイル名）を**新規作成**し、議事要約を書く。
2. 決まった「やること」は `04_次回以降のアクション` に移すか、ミーティングノートからリンクする（重複は最小に）。
3. スライドや台本の修正が必要なら `02_スライド` または `00_セミナー概要` の該当ファイルを更新する（ユーザーの指示があれば本文も編集可）。

## 親フォルダ `7_ローンチ` の並び

- `00_Skills/` … この運用の詳細・テンプレ（人間用の正本）
- `01_無料セミナー_OpenClaw5DAYS講座/` … 各回フォルダ
- `02_有料スクール_8週間ワークショップ/` …
- `03_スクール設計_商品・法務/` …
- `04_決済・インフラ/` …

## Do not

- ミーティング全文を `04_次回以降のアクション` に混ぜない（要約とタスクに分ける）。
- `02_スライド` に告知文やチャネル別コピーを置かない（それは `01_告知関連`）。
