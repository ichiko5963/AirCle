# スクール概要 ── AIで少人数で事業を回す実践コース

## コンセプト

### メインコンセプト
**「AI従業員を増やして、少人数で事業を回す」**

抽象的な「AIで分身を作る」ではなく、**具体的に「役割別のAI従業員を構築して、実務で回す」**ことにフォーカスしたスクール。

### なぜこのコンセプトなのか
- 5DAYS講座で「OpenClawでここまでできる」を体感した参加者が、「もっと深く学びたい」と思う自然な延長線
- 「AI分身」は抽象的すぎる → 「AI従業員」は具体的でビジネス層に刺さる
- 実際にいちが自分の事業で実践しており、再現性がある

### ターゲット
- 5DAYS講座に参加した人（最も確度が高い層）
- 起業家・個人事業主・中小企業経営者
  - 人を雇うコストを削減したい
  - AIで業務効率を上げたい
  - 少人数で事業をスケールさせたい
- 副業・複業をしている会社員
  - 本業以外の時間でAIに働いてもらいたい

## スクールの差別化ポイント

### 既存のAIスクールとの違い
| | 他のAIスクール | AirCleスクール |
| --- | --- | --- |
| 教えること | AIツールの使い方 | **AI従業員の作り方＋運用** |
| ゴール | ツールが使えるようになる | **事業の一部がAIで回るようになる** |
| アプローチ | 汎用的 | **あなたの事業に特化** |
| サポート | 動画教材＋質問対応 | **個別ハンズオン＋実装サポート** |
| 講師の実績 | AI評論家が多い | **自ら事業で実践している** |

### 3つの強み
1. **実践ベース**: いちが自分の事業で実際に使っているシステムをそのまま教える
2. **個別カスタマイズ**: 受講者の事業内容に合わせたAI従業員を一緒に構築
3. **コミュニティ**: 受講生同士のナレッジ共有・相互サポート

## カリキュラム（案）

### フェーズ1: 基盤構築（Week 1-2）
- OpenClaw環境構築（セキュリティ対策込み）
- Obsidian × GitHub の情報一元管理セットアップ
- APIキーの取得・管理
- 最初のAI従業員を1人作る（簡単なタスク自動化）

### フェーズ2: AI従業員育成（Week 3-4）
- コンテキスト設計：AI従業員に「あなたの判断基準」を教える
- 永続メモリの活用：使うほど賢くなる仕組み
- 役割別AI従業員の設計
  - 営業用・リサーチ用・経理用・広報用
- GitHub Actionsでデータ自動収集の設定

### フェーズ3: 事業への実装（Week 5-6）
- 受講者の事業に合わせたAI従業員の構築（個別サポート）
- 複数AI従業員の連携設計
- 承認フローの設計（セキュリティ）
- 運用開始＋最適化

### フェーズ4: スケール（Week 7-8）
- AI従業員の追加・拡張
- 自動化フローの改善
- 成果報告・ケーススタディ共有
- 卒業後のサポート体制
