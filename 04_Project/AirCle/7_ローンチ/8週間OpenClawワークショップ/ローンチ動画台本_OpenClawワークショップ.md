# ✅ 視聴者のストーリー（刺さるパート）

正直、多くの人が同じところで止まっています。

- 「OpenClawすごい」はわかった。でも**何からやればいいかわからない**
- 記事を読んでも**カタカナと英語だらけ**で、結局動けない
- **セキュリティが怖い**から、インストールの一歩手前で止まる
- ツールを入れたが、**結局ChatGPTと大差ない**使い方のまま

原因の多くは、**AIの性能じゃなくて「情報の一元管理（コンテキスト）」ができていないこと**にあります。

メモがバラバラ、過去の文脈がAIに渡らない。  
だから毎回ゼロから説明して、**「ただの便利なチャット」で終わる。**

5DAYSの第1回で話した**Obsidian × GitHub × OpenClaw**、第2回の**自律性・永続メモリ・ローカル**、第3回の**Xの3要素と分析→型化**、第4回の**Claude Code Channelsとの違いと開発のイメージ**──  
これらは全部、**「一本の線」でつながっている**。

特典の**10時間超**は、その線を頭に入れるための素材です。

# ✅ 本題：なぜ「ワークショップ」なのか

特典は**最高のインプット**です。  
でも、多くの人はここで止まる。

**「面白かった」で終わる。ノウハウコレクターになる。**

OpenClawは**魔法のツールじゃない**。  
触って、壊して、直して、メモリを育てて、週次で回す──**習慣と設計**がないと、結果は出ない。

だからAirCleでは、**8週間かけて、順番に作っていく**プログラムを用意しています。

【**テロップ：8週間の流れ（概要）**】

- **Step1** メモリ構築（環境・Obsidian・Cursor）
- **Step2** OpenClaw自動化・メモリ連携
- **Step3** マーケ活用（Xなど）
- **Step4** 業務自動化〜AI従業員構築

週1回セミナー想定、**Discord**で質問・宿題あり。  
**本気で手を動かして、自分の環境に落とし込みたい人**向けです。
