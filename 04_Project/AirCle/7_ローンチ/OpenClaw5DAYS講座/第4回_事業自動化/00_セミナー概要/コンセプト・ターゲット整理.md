# コンセプト・ターゲット整理

## セミナーのコンセプト
「チャットで事業を自動化する」── エンジニアじゃなくても開発できる時代を実演で証明する回

### 核心メッセージ
- プログラミングができなくても、チャットで話しかけるだけで業務システムが作れる
- OpenClawはLINEを送る感覚で事業の自動化ができる唯一のツール
- Claude CodeやCursorとは「誰のために作られたか」が決定的に違う
- 「自分がやりたい自動化って何？」を100個出せるぐらい、可能性の幅を見せる
- 中小企業・個人事業主にとって「人を雇う前にAIを雇う」という選択肢を提示

### 戦略的位置づけ（ユニコ会話より）
- Day 4は「開発」フォーカスだが、非エンジニアに向けた実演が中心
- ユニコ氏の「従業員分散管理の可視化」特別講義がこの回の目玉の一つ
- 「こんなこともできるの！？」の驚きを積み重ねる回
- Claude Code / Cursor / VS Code拡張機能との違いを明確に整理する
- 「自分の事業をぶん回す」というスクールコンセプトの直接的な訴求ポイント

## ターゲット層

### プライマリターゲット
- **AIで業務を自動化したいが、プログラミングができない人**
  - 「コードが書けない」ことを理由に自動化を諦めている
  - Claude CodeやCursorは聞いたことがあるが、ターミナルに抵抗がある

- **少人数で事業を回している起業家・事業家**
  - 雑務に時間を取られている（領収書、日報、メール返信etc.）
  - 人を雇う代わりにAIで解決したい
  - 事業のデータを可視化して意思決定を加速したい

### セカンダリターゲット
- **OpenClaw導入済みで自動化の具体例を知りたい人**
  - 第1〜3回からの継続参加者
- **Claude Code / Cursorを使っているが「もっと簡単な方法」を探している人**
  - ターミナル操作は面倒だと感じているエンジニア

## ペインポイント
1. プログラミングができないから自動化は自分には無理だと思っている
2. Claude Code / Cursorは話題だが、ターミナルに抵抗がある
3. 領収書・日報・メール返信などの繰り返し業務に毎日時間を取られている
4. 事業のデータが散らばっていて、全体像が見えない
5. 「AIで自動化したい」が、具体的に何をどう自動化すればいいかわからない

## ソリューション
1. OpenClawならチャットで話しかけるだけで業務自動化が可能であることを実演で証明
2. Claude Code vs OpenClawの明確な使い分けガイドを提供
3. 領収書処理・日報生成・メール返信・スケジュール最適化の具体的な自動化フローを公開
4. ユニコ氏による「組織データの可視化」特別講義で、経営判断の加速方法を学ぶ
5. 「自分の事業なら何を自動化するか」のアイデアが次々と湧いてくる状態を作る

## 期待される成果
- 「チャットで自動化できる」という新しい常識が腑に落ちる
- 自分の事業で自動化すべき業務が3つ以上明確になる
- Claude Code / Cursorとの違いを人に説明できるようになる
- 組織のデータ可視化の重要性と具体的な方法がわかる
- Day 5（AI従業員軍団）への期待値が最大化される
