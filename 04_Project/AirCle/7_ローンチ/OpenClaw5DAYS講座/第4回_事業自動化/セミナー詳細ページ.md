## セミナー概要（Peatix用）

◎概要

「プログラミングができないから、自動化は無理」

そう思っていませんか？

**その常識、もう終わりました。**

OpenClawを使えば、**Telegramのチャットに「領収書整理して」と打つだけ**で、領収書の自動整理システムが動きます。「毎朝の日報を自動で作って」と言えば、毎朝勝手に日報が生成されます。

コードを1行も書いていません。チャットで話しかけただけです。

「え、それってClaude Codeとかでもできるんじゃないの？」

できます。ただし、ターミナル（黒い画面）を開いて、コマンドを打って、環境設定をして......

**OpenClawは、それを全部「チャット」で済ませます。** LINEを送る感覚で、事業の自動化ができる。

今回の第4回では、講師いちが実際に自分の事業で使っている**自動化システムの全貌**を公開します。

さらに後半では、スクール生828人を指導してきた**ユニコ氏**が、「組織のデータを可視化して意思決定を加速する方法」を特別講義。中小企業・個人事業主が**今すぐ使える自動化の実例**を徹底解説します。

## セミナー内容

### 【いちパート】チャットで事業を自動化する

**Part 0: オープニング（5分）**
- 前回の振り返り（X運用の自動化）
- 今日のゴール：「チャットだけで事業の自動化ができる」ことを体感する

**Part 1: 「開発」のハードルが消えた（15分）**
- Claude Code vs OpenClaw ── 何が違うのか
  - Claude Code：ターミナル（黒い画面）でコマンドを打つ → エンジニア向け
  - OpenClaw：チャットで話しかけるだけ → 誰でも使える
- VS Code拡張機能の位置づけ（最近話題だが、本質は同じ）
- 「コードを書く」から「チャットで頼む」への革命
- なぜOpenClawは非エンジニアに優しいのか
  - ダウンロードするだけで使える
  - 自律性が高い（向こうから提案してくれる）
  - 全部チャットで完結する

**Part 2: 【実例公開】いちの自動化システム（25分）**
- **実例①：領収書・経費処理の自動化**
  - Before：PDFを1枚ずつ開いて、Excelに手入力
  - After：「今月の領収書整理して」→ 自動でスプレッドシートに整理
  - OpenClawへの指示の出し方（実際のチャット画面を公開）
- **実例②：日報の自動生成**
  - Before：毎日30分かけて日報を書く
  - After：OpenClawがカレンダー・メール・タスクを分析して自動生成
- **実例③：メール返信の下書き自動作成**
  - Before：30通のメールを1通ずつ読んで返信
  - After：OpenClawが重要度で分類し、返信の下書きを準備
- **実例④：スケジュール最適化**
  - OpenClawがカレンダーの空きを分析し、最適なスケジュールを提案

**Part 3: OpenClaw vs Claude Code ── 使い分けガイド（20分）**
- それぞれの得意領域を明確に
  - OpenClaw：日常業務の自動化、継続的なタスク、チャットベースの操作
  - Claude Code：大規模なコード生成、プロジェクト単位の開発
- 「どっちを使えばいいの？」に明確に答える
  - 非エンジニア → OpenClaw一択
  - エンジニア → 用途に応じて使い分け
- VS Code拡張機能 vs ターミナル vs デスクトップアプリの違い
- 「結局、OpenClawで十分」という場面が想像以上に多い理由

### 【ユニコ特別講義パート】

**Part 4: 組織のデータを可視化する（25分）**
- なぜ「データの可視化」が事業成長の鍵なのか
- 従業員のタスク・稼働を分散管理 → ビジュアライズする実例
- 事業データのダッシュボード化：売上・KPI・進捗を一目で把握
- 中小企業・個人事業主が今すぐ使える自動化の具体例
- OpenClawに「経営判断の材料」を作らせるという発想

**Part 5: まとめ + Q&A（15分）**
- 今日のポイント
  - コードを書かなくても、チャットで自動化できる時代
  - OpenClawは非エンジニアにとって最も優しい開発ツール
  - データの可視化で「感覚」ではなく「根拠」で判断できるようになる
