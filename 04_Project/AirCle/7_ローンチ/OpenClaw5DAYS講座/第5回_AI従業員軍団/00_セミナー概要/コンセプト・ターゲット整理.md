# コンセプト・ターゲット整理

## セミナーのコンセプト
「AI従業員軍団を作る」── 5日間の集大成＋スクールへの導線

### 核心メッセージ
- OpenClawを1つ動かすのは入口にすぎない。本当のゴールは「AI従業員軍団」
- 営業・経理・広報・リサーチ──役割別のAI従業員が24時間365日稼働する世界を実演で見せる
- 情報の一元管理（コンテキスト設計）こそがAI従業員の「育成」に不可欠
- 「すげえ」で終わらせず、「自分もやりたい」→ スクールへの自然な導線
- 「AIで少人数で事業をぶん回す」── これがスクールのコンセプトの直接体現

### 戦略的位置づけ（ユニコ会話より）
- ライブデモで「すげー」と思わせて終わることが最重要
- スクール紹介は最後20分で実施：いちが料金説明 → ユニコのティーアップ → ユニコ10分間ピッチ
- 料金はセミナー内で発表（税抜98,000円 ← ユニコスクール分の9,000円引き後）
- ユニコのスクールが全プランに付帯することを強調（実質無料で付いてくる）
- 「一回の冷やかしはやめてください」のスタンスで本気の人だけを集める
- 個別面談でクロージング（セミナーでは料金と申込方法まで）

### スクール概要（告知用）
- 形式：週1回オンラインセミナー × 8回以上（20:00-22:00）
- 期間：8週間
- プラットフォーム：Discord（ロール付与でアクセス管理）
- 宿題：毎週課題あり
- 内容：メモリ構築 → OpenClaw自動化 → X運用 → 事業自動化 → AI従業員構築
- ユニコスクール付帯：全プランに含まれる（AIエージェント数に応じたプラン設計）
- 決済：Upstory × ユニバペイ（審査完了次第）

## ターゲット層

### プライマリターゲット
- **5DAYS講座を通して参加してきた方**
  - OpenClawの可能性を理解し、さらに深く学びたい
  - 「自分もAI従業員を作りたい」と感じている

- **AIで「人を雇わずに事業を回す」方法に興味がある起業家・事業家**
  - 少人数経営で、人件費を抑えたい
  - AIエージェントで業務を代替したい

### セカンダリターゲット
- **「AI従業員」「AI分身」というコンセプトに興味がある人**
  - Day 5だけの参加も可能
- **スクールに興味がある潜在層**
  - 体系的に学びたい、個別サポートが欲しい

## ペインポイント
1. OpenClawを1つ動かしたが、その先の活用法がわからない
2. 「AI従業員」と言われても、具体的にどう作るかイメージが湧かない
3. 事業のあらゆる業務を自動化したいが、全体設計ができない
4. 情報の一元管理の重要性はわかったが、実装方法がわからない
5. 独学では限界がある。体系的に学べる場が欲しい

## ソリューション
1. 複数のOpenClawが同時に動くライブデモで「AI従業員軍団」を目撃する
2. 役割別AI従業員の設計方法（営業・経理・広報・リサーチ）を具体的に解説
3. 情報の一元管理（Obsidian × GitHub × OpenClaw）の全体アーキテクチャを提示
4. ユニコ氏との対談で「成功する人・失敗する人の違い」を知る
5. AirCleスクールへの案内：8週間の体系的なカリキュラム＋個別サポート

## 期待される成果
- 「AI従業員軍団」が実際に動いている世界を体感できる
- 情報の一元管理がなぜAI活用の「核」なのかを完全に理解できる
- 「自分の事業でどの役割からAI従業員を作るか」が明確になる
- 5DAYS講座で学んだ知識が1本の線として繋がる
- スクールという「次のステップ」の選択肢が手に入る
