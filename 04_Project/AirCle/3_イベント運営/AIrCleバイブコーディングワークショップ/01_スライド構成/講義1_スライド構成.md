## 【Part 2: パソコンの超基礎（スライド5-8）】

### スライド5: ファイル・フォルダ・パス
**タイトル**: デジタル世界の住所  
**内容**:
- **ファイル** = デジタルな1枚の紙（写真、文書、音楽）
- **フォルダ** = ファイルを入れる箱（引き出し）
- **パス** = ファイルの住所（`/Users/tanaka/Desktop/test.html`）  
**発表者ノート**: パソコンの中は「ジャングル」です。迷子にならないために「地図」が必要です。これがわかると、AIへの指示が正確になります。

### スライド6: 拡張子の魔法
**タイトル**: ファイル名の後ろの「.html」って何？  
**内容**:
- `.txt` = テキストファイル
- `.jpg` = 写真ファイル
- **`.html` = Webページファイル**（これが超重要！）  
**発表者ノート**: ファイル名の後ろにつく「.html」みたいなやつを「拡張子」と言います。これを変えるだけで、ファイルの種類が変わります。

### スライド7: パスの読み方
**タイトル**: デジタル世界の住所  
**内容**:
- `/Users/tanaka/Desktop/test.html`
- `/` = 「の中の」
- 例：`/Users/tanaka/Desktop/` = 「Usersの中のtanakaの中のDesktopの中」  
**発表者ノート**: パスは「住所」です。AIに「このファイルを修正して」と言うとき、パスを知っていると正確に伝えられます。

### スライド8: 【実践】自分のパソコンで確認
**タイトル**: 🛠️ やってみよう  
**手順**:
1. デスクトップに「vibe-coding」フォルダを作る
2. その中に「memo.txt」を作る
3. そのファイルのパスを確認する  
**発表者ノート**: 実際に手を動かすと、理解が深まります。MacならFinder、Windowsならエクスプローラーで確認できます。

## 【Part 4: 最初のWebページ作成（スライド13-16）】

### スライド13: AIにコードを書かせる
**タイトル**: 🛠️ エンジニアに発注  
**プロンプト例**:
```
「猫語翻訳機」を作りたいです。

機能：
- ボタンを押すと、ランダムで猫語（ニャー、ゴロゴロなど）が表示される

デザイン：
- 宇宙船のコックピットみたいな、カッコいい近未来的なデザイン

HTMLとCSS、JavaScriptを使って、
全部を1つのファイル（index.html）にまとめて書いてください。
```  
**発表者ノート**: AIがものすごい勢いで文字を書き始めます。これが「コード」です。

### スライド14: コピペでWebページを作る
**タイトル**: 🛠️ 魔法の瞬間  
**手順**:
1. Geminiが出したコードをコピー
2. メモ帳（Windows）またはテキストエディット（Mac）を開く
3. コードを貼り付け
4. **`cat.html`** という名前で保存（拡張子が`.html`が重要！）
5. ダブルクリックでブラウザで開く  
**発表者ノート**: これでアプリができました！コードは1文字も書いていません。コピペしただけです。

### スライド15: 動かしてみる
**タイトル**: 🛠️ 感動の瞬間  
**内容**:
- ブラウザが開いて、Webページが表示された！
- ボタンを押してみる
- 「ニャー」と表示される！  
**発表者ノート**: おめでとうございます！あなたが初めて（コピペで）作ったアプリです！

### スライド16: 修正を頼む
**タイトル**: 🛠️ もっと自分好みに  
**内容**:
- 「ボタンが小さすぎる！画面の半分くらいの大きさにして！」

**発表者ノート**: ここからが「バイブコーディング」です。気に入らないところを日本語で指摘してください。
