# 宿題1: カフェのホームページを作ろう

## この宿題でやること

4つの魔法のツールのどれか1つを使って、**カフェのホームページ**を作ります。

どのツールを使ってもOK。好きなのを選んでね。

---

## 準備するもの

- パソコン（スマホではできません）
- インターネット
- Googleアカウント（Gmailを持っていればOK）

---

## 4つのツールから1つ選ぼう

| ツール | 特徴 | こんな人におすすめ |
|--------|------|------------------|
| **Gemini** | 会話しながら作れる | 初めての人、相談しながら作りたい人 |
| **Genspark** | 検索するだけでできる | 一番簡単がいい人 |
| **Manus** | 細かく指示できる | こだわりたい人 |
| **v0** | デザインがおしゃれ | カッコよくしたい人 |

迷ったら、**GeminiかGenspark**がおすすめ！

---

## 選んだツールのやり方を見てね

下にそれぞれのやり方を書いてあるよ。自分が選んだツールのところを見てね。

---

# ツール①: Gemini（ジェミニ）の使い方

## 手順1: Geminiを開く

1. パソコンでブラウザ（ChromeかSafari）を開く

2. 上の検索バーに「gemini.google.com」と打つ

3. Enterを押す

4. Googleアカウントでログインする

## 手順2: キャンバスを開く

1. 画面の右上を見る

2. 「キャンバス」または「Canvas」というボタンを探す

3. そのボタンをクリック

4. 画面が2つに分かれたらOK！
   - 左側: お願いを書く場所
   - 右側: ホームページが表示される場所

## 手順3: カフェのホームページを作る

左側の入力欄に、以下をコピーして貼り付け、自分のカフェに変えてね：

```
カフェのホームページを作ってください。

カフェの名前:（ここに名前を入れる）
雰囲気:（どんな感じのカフェ？）
メニュー:
- （メニュー1）○○円
- （メニュー2）○○円
- （メニュー3）○○円
場所:（どこにあるカフェ？）
営業時間:（何時から何時まで？）

デザイン:（どんな見た目がいい？）
```

**例：**
```
カフェのホームページを作ってください。

カフェの名前: 森のコーヒー
雰囲気: 森の中にある静かなカフェ、木のぬくもりを感じる店内
メニュー:
- ブレンドコーヒー 400円
- カフェラテ 500円
- チーズケーキ 450円
場所: 東京都渋谷区
営業時間: 10:00〜19:00

デザイン: ナチュラルで落ち着いた感じ、緑と茶色を使って
```

## 手順4: 送信して待つ

1. 紙飛行機のマーク（送信ボタン）を押す
2. 10〜30秒くらい待つ
3. 右側にホームページが出てきたら成功！

## 手順5: 修正する

気に入らないところがあったら、そのまま言えばOK：

- 「背景をピンクにして」
- 「写真をもっと大きくして」
- 「お店の電話番号も追加して」
- 「もっとかわいい感じにして」

# ツール②: Genspark（ジェンスパーク）の使い方

## 手順1: Gensparkを開く

1. パソコンでブラウザを開く

2. 上の検索バーに「genspark.ai」と打つ

3. Enterを押す

4. 「Sign up」または「Get started」を押す

5. Googleアカウントでログインできるよ

## 手順2: 検索してホームページを作る

1. 検索バーが出てきたら、こう打つ：
   ```
   おしゃれなカフェのホームページ
   ```

2. 検索ボタンを押す

3. 検索結果が出てきたら「**Create Sparkpage**」ボタンを探す

4. そのボタンを押す

5. 数十秒待つと...ホームページが完成！

## 手順3: 自分のカフェに変える

できたページを見て、変えたいところがあったら：

1. ページの中にチャット機能がある

2. そこに「カフェの名前を『〇〇カフェ』に変えて」と打つ

3. 他にも：
   - 「メニューを変えて」
   - 「写真を変えて」
   - 「色を変えて」

---

# ツール③: Manus（マヌス）の使い方

## 手順1: Manusを開く

1. パソコンでブラウザを開く

2. 上の検索バーに「manus.im」と打つ

3. Enterを押す

4. 「Sign up」を押してアカウントを作る

5. Googleアカウントでログインできるよ

## 手順2: カフェのホームページを作る

チャット画面が出てきたら、以下をコピーして貼り付け、自分のカフェに変えてね：

```
カフェのホームページを作って。

カフェの名前:（ここに名前を入れる）
特徴:（このカフェの売りは何？）
メニュー:（メニューを書く）
場所:（どこにある？）
営業時間:（何時から何時？）

デザイン:（どんな見た目がいい？）
```

**例：**
```
カフェのホームページを作って。

カフェの名前: ビーチサイドカフェ
特徴: 海が見えるテラス席が人気、サンセットが綺麗
メニュー: スムージー、パンケーキ、サンドイッチ
場所: 神奈川県鎌倉市
営業時間: 10:00〜18:00

デザイン: 爽やかなブルーと白、海の写真をたくさん使って
```

## 手順3: 待つ

1. 送信ボタンを押す

2. Manusが自動でいろいろ作り始める（見てるだけでOK）

3. 数分かかるから、待っててね

4. 完成したら見てみよう！

---

# ツール④: v0（ブイゼロ）の使い方

## 手順1: v0を開く

1. パソコンでブラウザを開く

2. 上の検索バーに「v0.dev」と打つ

3. Enterを押す

4. 「Sign in」を押す

5. GitHubかGoogleでログインできるよ

## 手順2: カフェのホームページを作る

入力欄が出てきたら、以下をコピーして貼り付け、自分のカフェに変えてね：

```
カフェのランディングページを作って。

内容:
- ヒーローセクション（大きな写真とお店の名前）
- メニュー一覧
- お店の雰囲気の写真
- アクセス情報

カフェの名前:（ここに名前を入れる）
雰囲気:（どんな感じ？）
デザイン:（どんな見た目がいい？）
```

**例：**
```
カフェのランディングページを作って。

内容:
- ヒーローセクション（大きな写真とお店の名前）
- メニュー一覧
- お店の雰囲気の写真
- アクセス情報

カフェの名前: 夜のカフェ
雰囲気: 夜だけ開いている秘密のカフェ、大人の隠れ家
デザイン: ダークモードで高級感、おしゃれなフォントで
```

## 手順3: 待つ

1. 送信ボタンを押す

2. 数秒〜数十秒で、デザインが出てくる

3. 気に入らなかったら「もっとこうして」と言えばOK

# 共通: スマホで見る方法

## 手順1: URLをコピーする

作ったホームページには、URLがあるよ。

- Gemini: 右側のページの上のほうに「共有」ボタンがある
- Genspark: ページのURLをコピー
- Manus: 完成したページのURLをコピー
- v0: ページのURLをコピー

## 手順2: スマホに送る

コピーしたURLを、自分のスマホに送ろう：

- LINEで自分宛にメッセージを送る
- メールで自分宛に送る

## 手順3: スマホで開く

スマホでそのURLをタップして開いてみて！

# 提出するもの

## 提出物1: ホームページのスクリーンショット

パソコンの画面に映っている、自分が作ったホームページの写真を撮ってね。

**スクリーンショットの撮り方：**
- Windows: キーボードの「PrtSc」を押す
- Mac: 「Command + Shift + 3」を同時に押す

## 提出物2: ホームページのURL

作ったページのURLをメモしておいてね。

## 提出物3: 見せた人の反応

誰かに見せて、何て言われたか教えてね。

例：
- 「すごいって言われた」
- 「どうやって作ったの？って聞かれた」
- 「へえー、って感じだった」

---

# 提出のしかた

## 方法1: フォルダにまとめる

1. パソコンのデスクトップに「宿題1」フォルダを作る
2. スクリーンショットをそのフォルダに入れる
3. メモ帳を開いて、URLと感想を書いて「メモ.txt」で保存
4. そのフォルダを先生に送る

## 方法2: LINEで送る

1. スクリーンショットを送る
2. URLを送る
3. 「〇〇に見せたら、△△って言われました」と送る

# 困ったときは

## ページが開けない
- インターネットにつながっているか確認
- 違うブラウザで試してみる

## ログインできない
- Googleアカウントが正しいか確認
- パスワードを忘れた場合はリセット

## ホームページが出てこない
- もう少し待ってみる（1分くらい）
- ページを更新して、もう一度やってみる

## それでもダメなとき
- 先生に聞いてね！
