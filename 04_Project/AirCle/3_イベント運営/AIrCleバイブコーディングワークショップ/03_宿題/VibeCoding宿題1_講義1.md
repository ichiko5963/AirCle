# 📝 VibeCoding宿題1: 講義1「バイブコーディング入門」

## 🎯 宿題の目的

講義1で学んだ「AIとの対話」と「魔法のツール」を実際に使って、**自分だけのWebページやアプリを作る**体験をしてもらいます。

---

## 📋 宿題内容

### 【必須課題】3つすべてに取り組んでください

---

### 1. Geminiとおしゃべり（30分）

**目的**: AIとの対話に慣れる

**手順**:
1. `gemini.google.com` にアクセスしてログイン
2. 以下の3つの質問を順番に聞いてみてください：

   **質問1**: 「私はプログラミング初心者です。自分専用の家計簿アプリを作りたいと思っています。どんな機能があったら便利だと思いますか？3つ教えてください。」

   **質問2**: （質問1で出てきたアイデアから1つ選んで）「その『〇〇機能』について、もっと詳しく教えて。どんな画面になるか、どんな操作をするか、具体的にイメージを教えて。」

   **質問3**: 「そのアプリを作るために、まず何から始めればいいですか？初心者でもできる手順を3ステップで教えて。」

3. Geminiの回答を読んで、気になったところをさらに質問してみてください

**提出物**: 
- Geminiとの会話のスクリーンショット（3枚以上）
- または、会話の内容をコピーしてノートにまとめる

---

### 2. GensparkかManusで何か1つ作る（30分）

**目的**: 魔法のツールを実際に使う

**選択肢A: Gensparkで情報サイトを作る**

1. `genspark.com` にアクセス
2. 興味のあるテーマで検索（例：「おすすめのカフェ」「初心者向け筋トレ方法」「プログラミング学習のコツ」など）
3. 「Create Sparkpage」をクリック
4. 完成したサイトを確認
5. チャット機能で「もっと画像を増やして」「目次をつけて」など修正を試す

**選択肢B: Manusでアプリを作る**

1. Manusにアクセス（`manus.ai` など）
2. 以下のようなプロンプトでアプリを作ってみる：

   ```
   簡単な「今日のやることリスト」アプリを作って。
   タスクを追加・削除・完了チェックができる機能で。
   デザインはシンプルで、朝の爽やかな感じで。
   ```

3. 完成したアプリを確認
4. 「ここを変えて」と修正を試す

**提出物**:
- 作成したサイト/アプリのURL
- または、スクリーンショット（3枚以上）
- 作成過程で「面白かった」「困った」などの感想を1行で

---

### 3. スマホで確認して友達に見せる（10分）

**目的**: 「作ったものが動く」感動を味わう

**手順**:
1. GensparkやManusで作ったサイト/アプリのURLをスマホに送る（LINEやメールで自分に送る）
2. スマホでそのURLを開く
3. ちゃんと表示されるか確認
4. 友達や家族に「これ、AIで作ったの！」と見せてみる

**提出物**:
- スマホで開いた画面のスクリーンショット（1枚）
- 友達の反応を1行で（例：「すごいって言われた！」「え、本当に作ったの？って驚かれた」）

## 📝 提出方法

以下のいずれかの方法で提出してください：
