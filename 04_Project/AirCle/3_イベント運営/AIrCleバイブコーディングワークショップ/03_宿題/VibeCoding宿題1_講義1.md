# 宿題1: はじめてのホームページを作ろう

## この宿題でやること

Geminiというサービスを使って、**自分だけのホームページ**を作ります。

プログラミングの知識は一切いりません。日本語で「こんなページ作って」とお願いするだけです。

---

## 準備するもの

- パソコン（スマホではできません）
- インターネットにつながっていること
- Googleアカウント（Gmailを持っていればOK）

Googleアカウントを持っていない人は、お父さんお母さんに聞いてみてください。

---

## やること1: Geminiを開く

### 手順

1. パソコンでGoogle Chrome（またはSafari）を開く

2. 画面の上のほうにある「検索バー」に、これを打ち込む:
   ```
   gemini.google.com
   ```

3. Enterキーを押す

4. Googleのログイン画面が出たら、自分のGoogleアカウントでログインする
   - メールアドレスを入れる
   - パスワードを入れる

5. こんな画面が出てきたら成功！
   - 画面の下のほうに、文字を打ち込める場所がある
   - ここにお願いごとを書くと、AIが答えてくれる

---

## やること2: 「キャンバス」を開く

### 手順

1. Geminiの画面の**右上のほう**を見る

2. 「キャンバス」または「Canvas」と書いてあるボタンを探す
   - 四角いアイコンみたいなものがついているかもしれない

3. そのボタンをクリック

4. 画面が2つに分かれる
   - 左側: Geminiとおしゃべりする場所
   - 右側: ホームページが表示される場所

これで準備完了！

---

## やること3: ホームページを作る

### 手順

1. 画面の左下にある入力欄（文字を打つところ）に、以下をコピーして貼り付ける:

```
自己紹介のホームページを作ってください。

内容:
- 名前: （ここに自分の名前を入れる）
- 好きなこと: （ここに自分の好きなことを入れる）
- 夢: （ここに将来の夢を入れる）

デザイン:
- かわいい感じ
- 背景は水色
- 文字は読みやすく
```

2. 「（ここに〜を入れる）」の部分を、自分の情報に書き換える

例:
```
自己紹介のホームページを作ってください。

内容:
- 名前: たなか ゆうき
- 好きなこと: ゲーム、サッカー、猫
- 夢: ゲームクリエイターになりたい

デザイン:
- かわいい感じ
- 背景は水色
- 文字は読みやすく
```

3. 書けたら、紙飛行機のマーク（送信ボタン）を押す

4. **待つ**（10秒〜30秒くらい）

5. 右側の画面に、ホームページが出てきた！

---

## やること4: ホームページを自分好みに変える

作ったホームページ、ちょっと気に入らないところがあるかもしれない。

そんなときは、**文句を言えばOK**です。

### 変えたいときのお願いの仕方

**色を変えたいとき:**
```
背景をピンクに変えて
```

**文字を大きくしたいとき:**
```
名前の文字をもっと大きくして
```

**写真を追加したいとき:**
```
猫の写真を追加して
```

**全体の雰囲気を変えたいとき:**
```
もっとカッコよくして。宇宙っぽい感じで
```

何度でも変えられるから、どんどん試してみよう！

---

## やること5: 作ったホームページをスマホで見る

### 手順

1. 右側に表示されているホームページの上のほうを見る

2. 「共有」または「シェア」ボタンを探す
   - ない場合は、URLをコピーするボタンを探す

3. URLをコピーする

4. そのURLを、自分のスマホに送る
   - LINEで自分に送る
   - メールで自分に送る
   - どちらでもOK

5. スマホでそのURLを開く

6. 自分が作ったホームページが表示される！

### 手順

1. 家族か友達に声をかける

2. 「ねえ、これ見て。私が作ったホームページ！」と言う

3. スマホの画面を見せる

4. 相手が何て言ったか、覚えておく

## 提出するもの

以下の3つを提出してください。

### 提出物1: ホームページの写真

- パソコンの画面に映っている、自分が作ったホームページの写真を撮る
- または、スクリーンショットを撮る
  - Windows: キーボードの「PrtSc」を押す
  - Mac: 「Command + Shift + 3」を同時に押す

### 提出物2: ホームページのURL

- やること5でコピーしたURLを、メモに残しておく

### 提出物3: 誰かに見せたときの反応

- 例:「すごいって言ってくれた」
- 例:「どうやって作ったの？って聞かれた」
- 例:「ふーん、って感じだった」

どんな反応でもOK。正直に書いてね。

---

## 提出のしかた

### 方法1: フォルダにまとめる

1. パソコンのデスクトップに「宿題1」というフォルダを作る
2. スクリーンショットをそのフォルダに入れる
3. メモ帳を開いて、URLと反応を書いて「感想.txt」として保存
4. そのフォルダを先生に送る

### 方法2: LINEで送る

1. スクリーンショットを先生にLINEで送る
2. URLを送る
3. 「〇〇に見せたら、△△って言ってました」と送る

---

## 困ったときは

### 「Geminiが開けない」

- インターネットにつながっているか確認する
- Googleアカウントでログインできているか確認する
- 違うブラウザで試す（ChromeがダメならSafariで）

### 「キャンバスが見つからない」

- Geminiの画面をよく見て、「Canvas」という文字を探す
- 見つからない場合は、Geminiに直接「キャンバスを開いて」と打ち込んでみる

### 「ホームページが出てこない」

- もう少し待ってみる（1分くらい）
- 一度ページを更新して、もう一度お願いしてみる

### 「URLがわからない」

- ブラウザの一番上に表示されている文字列（https://で始まるやつ）がURL
- それをコピーすればOK

### それでもダメなとき

- 先生に聞いてね！

## もっとやりたい人へ（チャレンジ課題）

自己紹介ページ以外にも、いろんなページを作ってみよう！

### アイデア1: 好きなものランキング

```
私の好きな食べ物ランキングのページを作って。

1位: ラーメン
2位: 寿司
3位: カレー

それぞれに一言コメントもつけて。デザインはポップな感じで。
```

### アイデア2: 今日の日記

```
今日の日記のページを作って。

日付: 2026年1月18日
タイトル: 楽しい一日

今日あったこと:
- 朝ごはんにパンケーキを食べた
- 友達と公園で遊んだ
- 宿題を終わらせた

写真を1枚入れて、温かみのあるデザインにして。
```

### アイデア3: 推しのページ

```
私の推しを紹介するページを作って。

推しの名前: （好きなキャラクターや芸能人の名前）
好きなところ: （3つくらい書く）

ファンページっぽい、キラキラしたデザインで。
```
