# 📝 VibeCoding宿題3: 講義3「Webの仕組みとデータベース」

## 🎯 宿題の目的

講義3で学んだ「Supabase」と「認証機能」を実際に使って、**データが消えない、自分だけのアプリ**を作る体験をしてもらいます。

---

## 📋 宿題内容

### 【必須課題】「買い物リスト」アプリを作る

---

### 1. Supabaseでプロジェクトを作る（10分）

**手順**:
1. `supabase.com` にアクセスしてログイン
2. 「New Project」をクリック
3. プロジェクト名：`shopping-list`（または好きな名前）
4. パスワードを設定して「Create Project」
5. 数分待って、プロジェクトが完成するのを確認

**提出物**: Supabaseのプロジェクト一覧のスクリーンショット

---

### 2. テーブルを作る（AIに頼む）（10分）

**手順**:
1. Supabaseの左メニューから「SQL Editor」を開く
2. 「AI SQL Editor」またはチャット機能を使う
3. 以下のプロンプトを入力：

   ```
   買い物リストアプリ用のテーブルを作って。
   カラムは以下：
   - 商品名（text）
   - 数量（integer）
   - 購入済みフラグ（boolean）
   - 作成日時（timestamp）
   - ユーザーID（uuid、認証用）
   ```

4. 実行ボタンを押してテーブルを作成
5. 「Table Editor」でテーブルができているか確認

**提出物**: 作成されたテーブルのスクリーンショット

---

### 3. Antigravityでアプリを作る（30分）

**手順**:
1. Antigravityで新しいプロジェクトを作成（Next.js）
2. Supabaseの接続情報（URLとanon key）を `.env` に設定
3. AIエージェントに以下の指示を出す：

   ```
   買い物リストアプリを作って。
   機能：
   - 商品名と数量を入力して追加できる
   - リストに表示される
   - 購入済みにチェックを入れられる
   - 削除ボタンで削除できる
   - Supabaseにデータを保存する
   - リロードしてもデータが消えない
   
   デザインはシンプルで使いやすく。
   ```

4. AIがコードを書くのを待つ
5. プレビューで動作確認

**提出物**: 
- Antigravityの画面のスクリーンショット（アプリが動いている様子）
- または、作成したアプリのURL

---

### 4. マジックリンクでログイン機能をつける（20分）

**手順**:
1. Supabaseの `Authentication` -> `Providers` でEmail認証をONにする
2. `Site URL` にAntigravityのプレビューURLを設定
3. AntigravityのAIエージェントに指示：

   ```
   ログイン機能を追加して。
   - ログイン画面を作る
   - メールアドレスを入力するとマジックリンクが送られる
   - ログインしていない場合はログイン画面にリダイレクト
   - ログインしている場合は買い物リストが表示される
   - 右上にログアウトボタンを追加
   ```

4. メールアドレスを入力して、マジックリンクでログインできるか確認

**提出物**: ログイン画面とログイン後の画面のスクリーンショット

---

### 5. RLS（セキュリティ）を設定する（15分）

**手順**:
1. Supabaseの `Authentication` -> `Policies` を開く
2. 作成したテーブルの「Enable RLS」をONにする
3. AI SQL Editorに以下のプロンプトを入力：

   ```
   user_idが自分のIDと一致する行だけ、
   SELECT（読み取り）、INSERT（追加）、UPDATE（更新）、DELETE（削除）
   ができるポリシーを作って。
   ```

4. ポリシーを実行
5. シークレットモードで別のアカウントでログインして、他の人のリストが見えないか確認

**提出物**: RLSポリシーの設定画面のスクリーンショット

---

### 6. 家族と共有する（10分）

**手順**:
1. AntigravityのプレビューURLをコピー
2. 家族や友達にURLを送る
3. それぞれが自分のメールアドレスでログイン
4. それぞれのリストが独立していることを確認
5. 一人が追加した商品が、他の人の画面には表示されないことを確認

**提出物**: 
- 家族の反応を1行で（例：「便利って言われた！」「使ってくれた！」）
- または、複数のアカウントでログインした画面のスクリーンショット

## 💡 困ったときは

- 「Supabaseの接続がうまくいかない...」→ `.env` ファイルのURLとキーが正しいか確認してください。`VITE_` プレフィックスが必要な場合があります
- 「マジックリンクが届かない...」→ Supabaseの `Site URL` が正しく設定されているか確認してください。AntigravityのプレビューURLをそのまま貼り付けてください
- 「RLSでデータが見えない...」→ ポリシーが正しく設定されているか、AIに「RLSのポリシーを確認して」と聞いてみてください
